# 首页精简设计

目标：让访客先理解研究主线，再查看代表成果或发起联系。沿用现有字体、配色、版心与手机导航。

## 阅读顺序

1. **身份与定位**：Huawei 身份、简短介绍、一组 Current focus、研究 / 论文 / 实习入口。保留手机首屏精选直达链接。
2. **两条研究主线**：保留问题说明；四张贡献卡片改为简洁的代表作条目，展示机制及带条件的证据，链接到完整 Digest。研究演进收为两句，不再重复列出 14 个论文标题。
3. **六篇精选**：成员、顺序、图片、摘要和链接全部保持不变。
4. **招聘与联系**：一句明确招聘提示、邮箱及 Scholar / GitHub / LinkedIn。删除每个联系方式的重复说明；RecArch 移到现有资源页。

首页不再展示 Latest updates。历史事件保留在原数据及 API 中；WSDM 两篇录用的补充信息随对应论文进入 Full publications，避免只保留其中一篇的事实。

## 分页与兼容

- Collaborations 删除统计板与泛化的三类合作卡片；招聘条件、申请说明和邮件草稿入口先于研究方向；保留合作机构记录。
- 保留所有页面 URL 和研究主线锚点。`#updates`、`#recent-publications` 指向精选与完整列表入口；`#trajectory` 指向简短演进段落。
- FAQ、Summary、论文详情、专利和机器接口不删。新闻与研究演进的原始数据仍供 API 使用。
- 不增加框架、依赖、字体、图片、页面或前端脚本。删除仅服务于被移除模块的样式。

## 涉及文件

`index.md`、`collaborations.md`、`resources.md`、`publications.md`、共享样式及其版本引用、现有验收脚本、README 与维护指南。论文数据和六篇精选模板保持原样。

## 验收

- Jekyll 构建与现有全站检查通过；核对论文元数据、JSON、canonical、站内链接与旧锚点。
- 与改动前产物比较，六篇精选 HTML 完全一致；招聘条件和邮件草稿内容不变。
- 手机菜单、44px 触控目标、精选直达、长标题换行和键盘焦点样式保留。
- 检查桌面及手机布局；若浏览器不可用，报告未完成的视觉检查，不把静态检查称为浏览器实测。
- 推送后核对对应提交的 GitHub Pages 构建及线上页面 / CSS。

## 本地验收结果

- 仅包含受版本管理文件的发布快照构建成功；全站检查通过 1,643 项，覆盖 29 篇论文。
- 六篇精选的卡片 HTML 与修改前逐字相同；申请邮件模板、合作机构记录及文献 / 主题 / 项目 / 专利 API 内容相同。
- 首页板块由 6 个减为 4 个。按空格分词，排除脚本、样式与默认折叠内容后，正文词数由 1,071 降至 492；此数值不代表访问量或页面高度。
- CSS 语法检查通过；手机断点、44px 触控规则、换行与焦点样式已做静态核对。
- 当前会话浏览器不可用，未完成新的桌面 / 手机渲染与点击实测；此前的手机验收不能替代本轮视觉检查。
